# 뉴스 팩토리 (news-factory)

이 프로젝트는 광주광역시와 전라남도 지역의 소식을 자동으로 모아서 읽기 좋은 기사로 만들어주는 똑똑한 로봇 기자 시스템입니다.

## 이 프로젝트가 하는 일

우리 동네의 새로운 소식은 보통 시청이나 군청 홈페이지의 보도자료 게시판에 올라옵니다. 하지만 27개나 되는 지자체 홈페이지를 매일 하나씩 방문해서 확인하는 일은 매우 번거롭습니다.

뉴스 팩토리는 마치 성실한 기자처럼 정해진 시간마다 이 사이트들을 대신 방문합니다. 홈페이지에 올라온 복잡한 공문서 형태의 보도자료를 읽고, 인공지능(AI)을 사용해서 사람들이 읽기 편한 뉴스 기사로 다시 작성합니다. 이렇게 만들어진 기사들은 다른 서비스에서도 사용할 수 있도록 깔끔하게 정리되어 제공됩니다.

## 어떻게 동작하나요?

뉴스 팩토리는 다음과 같은 단계를 거쳐 일을 합니다.

1. 자동 시작: 정해진 시간(아침, 점심, 저녁)이 되면 컴퓨터가 자동으로 수집 로봇을 깨웁니다.
2. 정보 수집: 로봇이 광주와 전남의 27개 관공서 홈페이지를 방문해서 새로운 글이 있는지 확인하고 내용을 가져옵니다. 이 과정을 크롤링이라고 부릅니다.
3. 저장: 가져온 원본 글들을 안전하게 데이터베이스 창고에 차곡차곡 쌓아둡니다.
4. 기사 작성: 인공지능이 창고에 저장된 원본 내용을 읽고, 핵심 내용을 파악해서 부드러운 말투의 기사로 다시 씁니다.
5. 배달: 완성된 기사들은 필요한 사람들이 언제든지 가져갈 수 있도록 문을 열어둡니다. 이것을 API라고 합니다.

## 사용된 기술

컴퓨터를 잘 모르는 친구들도 이해할 수 있게 간단히 설명해 드릴게요.

* Next.js 16.1.6 (React 19): 웹사이트의 뼈대와 화면을 만드는 가장 현대적인 도구입니다.
* TypeScript: 프로그램 코드를 짤 때 실수를 줄여주는 똑똑한 언어입니다.
* Supabase: 수집한 정보를 잃어버리지 않게 보관하는 튼튼한 온라인 창고입니다.
* Tailwind CSS v4: 웹사이트의 색깔이나 모양을 예쁘게 꾸며주는 도구입니다.
* Cheerio: 홈페이지에 있는 글자들 중에서 필요한 내용만 쏙쏙 뽑아오는 분석 도구입니다.
* Axios: 인터넷을 통해 다른 컴퓨터와 정보를 주고받는 통신 수단입니다.
* p-limit: 너무 많은 정보를 한꺼번에 요청해서 상대방 웹사이트가 힘들어하지 않게 조절해주는 장치입니다.
* bcryptjs: 비밀번호를 암호로 바꿔서 아무도 볼 수 없게 보호하는 보안 기술입니다.

## 수집 대상 사이트 (27개)

뉴스 팩토리는 다음 지역의 소식들을 모으고 있습니다.

### 광주 지역 (6개)
광주광역시, 동구, 서구, 남구, 북구, 광산구

### 전남 지역 (1개)
전라남도

### 전남 시, 군 지역 (20개)
목포시, 여수시, 순천시, 나주시, 광양시, 담양군, 곡성군, 구례군, 고흥군, 보성군, 화순군, 장흥군, 강진군, 해남군, 영암군, 완도군, 진도군, 신안군, 영광군, 무안군

## 프로젝트 구조

컴퓨터 안의 폴더들이 어떤 역할을 하는지 알려드릴게요.

* app/: 우리가 실제로 보는 웹사이트 화면들이 들어있는 폴더입니다.
* components/: 화면을 구성하는 작은 부품들이 모여 있습니다.
* lib/: 정보를 수집하거나 인공지능에게 일을 시키는 핵심 기능들이 들어 있습니다.
* scripts/: 자동으로 일을 처리할 때 사용하는 도구 모음입니다.
* public/: 이미지나 로고 같은 파일들이 보관되어 있습니다.

## 시작하기 (로컬 실행 방법)

내 컴퓨터에서 이 프로젝트를 실행해보려면 다음 순서대로 따라 하세요.

1. 프로젝트 파일을 내 컴퓨터로 가져옵니다.
```bash
git clone https://github.com/your-repo/news-factory_v2
cd news-factory_v2
```

2. 필요한 도구들을 설치합니다.
```bash
npm install
```

3. 환경 설정 파일을 만듭니다. .env.example 파일을 복사해서 .env.local 파일을 만들고 내용을 채워 넣으세요.

4. 프로그램을 실행합니다.
```bash
npm run dev
```

5. 이제 인터넷 창을 열고 주소를 입력하세요.
* 일반 화면: http://localhost:3000
* 관리자 화면: http://localhost:3000/admin

## 관리자 대시보드

관리자만 들어갈 수 있는 특별한 페이지들이 8개 있습니다.

* 대시보드: 지금 몇 개의 기사가 모였는지 요약해서 보여줍니다.
* 보도자료 관리: 수집한 원본 글들의 목록을 보고 필요 없는 것은 지울 수 있습니다.
* 기사 관리: 인공지능이 쓴 기사들을 확인하고 관리합니다.
* 크롤링 수동 실행: 정해진 시간까지 기다리지 않고 지금 바로 정보를 수집하게 시킵니다.
* 크롤링 모니터링: 지금 로봇이 어느 홈페이지에서 정보를 가져오고 있는지 실시간으로 확인합니다.
* 크롤링 설정: 특정 지역의 수집 기능을 켜거나 끌 수 있습니다.
* API 클라이언트 관리: 외부에서 정보를 가져갈 수 있는 권한 카드(키)를 만들어줍니다.
* 통계: 날짜별로 얼마나 많은 정보가 들어왔는지 숫자로 자세히 보여줍니다.

## API 사용법

다른 프로그램이 뉴스 기사를 가져갈 때 사용하는 길입니다.

* 기사 목록 가져오기: GET /api/v1/articles
* 기사 하나만 자세히 보기: GET /api/v1/articles/:id
* 주제 목록 보기: GET /api/v1/categories
* 지역 목록 보기: GET /api/v1/regions

정보를 가져가려면 관리자 화면에서 발급받은 비밀번호(Bearer 토큰)가 필요합니다. 너무 자주 요청하면 잠시 제한될 수 있습니다.

## 스크립트 목록

명령어를 통해 특정 일만 시킬 수 있는 13가지 도구입니다.

1. run-pipeline.ts: 수집부터 기사 작성까지 전체 과정을 한 번에 실행합니다.
2. crawl.ts: 홈페이지에서 정보를 가져오는 일만 시킵니다.
3. generate.ts: 이미 가져온 정보를 바탕으로 인공지능에게 기사를 쓰게 합니다.
4. embed.ts: 정보를 나중에 찾기 쉽게 특수한 숫자 형태로 변환합니다.
5. list-sites.ts: 지금 수집하고 있는 27개 사이트가 어디인지 목록을 보여줍니다.
6. test-crawl.ts: 특정 사이트에서 정보를 잘 가져오는지 미리 확인해봅니다.
7. test-detail.ts: 특정 글의 내용을 로봇이 잘 읽는지 시험해봅니다.
8. count-pr.ts: 지금까지 수집한 원본 글이 총 몇 개인지 숫자를 알려줍니다.
9. reprocess.ts: 이미 기사가 있어도 인공지능에게 다시 써달라고 시킵니다.
10. reset-articles.ts: 만들어진 기사들을 전부 지우고 처음부터 다시 시작합니다.
11. delete-all-prs.ts: 수집한 모든 원본 글을 깨끗이 지웁니다.
12. check-crawl-settings.ts: 현재 수집 규칙들이 잘 설정되어 있는지 확인합니다.
13. setup-crawl-settings.ts: 수집 규칙들을 처음 상태로 정렬합니다.

## 환경 변수

프로그램이 작동하는 데 필요한 비밀 정보들입니다. .env 파일에 적어줍니다.

* SUPABASE_URL: 정보 저장고의 주소입니다.
* SUPABASE_SERVICE_KEY: 저장고를 관리하는 강력한 열쇠입니다.
* SUPABASE_ANON_KEY: 저장고의 정보를 읽을 때 쓰는 공개 열쇠입니다.
* OLLAMA_API_URL: 나중에 사용할 다른 인공지능 도구의 주소입니다.
* OPENROUTER_API_KEY: 기사를 써주는 인공지능을 사용하기 위한 통행료 카드입니다.
* OPENROUTER_MODEL: 인공지능 모델의 이름을 적습니다.
* CRON_SECRET: 정해진 시간마다 자동으로 작동하게 하는 비밀 신호입니다.
* SITE_PASSWORD: 관리자 화면에 들어갈 때 쓰는 비밀번호입니다.

## 자동 실행 (GitHub Actions)

이 프로그램은 사람이 직접 실행하지 않아도 매일 3번 스스로 일을 시작합니다. 한국 시간으로 아침 6시, 낮 12시, 저녁 6시에 로봇이 깨어나서 27개 사이트를 돌아다니며 새로운 소식을 찾습니다. 이를 통해 우리는 항상 최신 지역 소식을 놓치지 않고 확인할 수 있습니다.
